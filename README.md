# WinForge 安装包发布平台（公开版）

一个简单好用的 Windows 安装包发布平台，任何人都可以在线发布自己的安装包（.exe / .msi / .zip 等），平台会对发布内容进行自动审核，审核通过后即可公开下载。

## 功能特性

- 在线发布安装包：支持 .exe / .msi / .zip / .7z / .rar / .appx / .msix / .bat / .cmd / .sb3 / .apk / .dmg 等常见格式
- 智能命名校验：自动过滤不当词汇，为你的安装包起个文明的名字
- 公开统计：首页实时展示已上线与待审核作品数量
- 安全下载：仅已审核通过的文件对外提供下载，审核中文件对外不可见

## 快速开始

### 环境要求

- Python 3.8+
- pip

### 安装依赖

```bash
pip install -r requirements.txt
```

### 启动服务

```bash
python server.py
```

启动后访问：

- 前台首页：http://127.0.0.1:5000/
- 发布页：http://127.0.0.1:5000/publish.html

### 发布流程

1. 打开发布页，为你的安装包起一个名字（50 字以内，不能包含不当词汇）
2. 选择或拖入安装包文件
3. 点击发布，文件将进入待审核状态
4. 审核通过后，文件即正式上线，访客可通过首页公开下载

## 目录结构

```
winforge-public/
├── server.py               # 主服务（公开版）
├── requirements.txt        # 依赖清单
├── static/
│   ├── index.html          # 前台首页
│   ├── publish.html        # 发布页
│   └── css/
│       └── style.css       # 样式
└── uploads/
    ├── pending/            # 待审核文件（对外不可见）
    ├── approved/           # 已审核上线文件（公开下载）
    └── records.json        # 发布记录（首次发布后自动生成）
```

## 项目说明

- 上传的文件会以「时间戳 + 随机串 + 安全文件名」的形式保存在 `uploads/pending` 目录，避免重名覆盖
- 只有已审核通过（位于 `uploads/approved`）的文件才会生成公开下载地址
- 本项目为公开版，不包含管理员后台功能
